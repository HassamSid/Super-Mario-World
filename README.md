## Getting started

1- Install Java JDK if your system doesn't have it already. https://download.oracle.com/java/26/latest/jdk-26_windows-x64_bin.exe

2- In the Game.java there is a variable named Directory, replace the path of mario game folder where you have placed it in your system.

3- Lastly execute Demo.java to run the game.
